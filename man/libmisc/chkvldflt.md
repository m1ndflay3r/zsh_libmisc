## chkvldflt - *return 0 if input is valid floating point number, 1 if not*

------------------------------------------------------------

**example:**

    chkvldflt "123456.789"

-----------------------------------------------------------

notes:

  - set hex=1 to enable ints in hex format

  - expects first and last char to not be a decimal point (so ".123" or "123." are not valid floats)
